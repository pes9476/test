# Aegis Wallet

The current React Native mobile app is in [`Myapp/`](Myapp/). Its wallet, transfer form, FDS alert feed, and transaction ticker are implemented in [`Myapp/App.tsx`](Myapp/App.tsx).

The Expo app at the repository root is the earlier web/mobile prototype. The mobile app currently uses synthetic transaction data and a local demo verdict; it is not connected to the planned FDS backend.

To work on the native app, open `Myapp/` in VS Code. See its README for the standard React Native development commands.
